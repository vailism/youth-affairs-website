---

## 🏛️ About Youth Affairs

**Youth Affairs** provides a dynamic, high-impact platform for youth to engage in meaningful discourse, governance simulations, and constructive debate. By convening students, aspiring leaders, and change-makers from across the nation, Youth Affairs bridges the gap between academic theory and real-world policy making.

Through flagship national initiatives such as **Yuva Sansad** (Youth Parliament) and **Model United Nations (MUN)** conferences, delegates dissect critical socioeconomic issues, debate national and international policies, formulate resolutions, and cultivate essential 21st-century leadership skills.

### Vision & Mission
- **Empower Dialogue:** Promote an inclusive, civil space where diverse voices debate with intellectual rigor.
- **Nurture Leadership:** Cultivate strategic decision-making, ethical leadership, and consensus-building skills.
- **Drive Civic Engagement:** Deepen understanding of parliamentary procedure, constitutional values, and international diplomacy.
- **Inspire Innovation:** Encourage bold, pragmatic solutions to contemporary national and global challenges.

## 💻 Tech Stack & Architecture

Built with modern web standards prioritizing performance, accessibility, and visual elegance:

- **Semantic HTML5** — Accessible document structure, SEO-optimized meta tags, OpenGraph previews.
- **Vanilla CSS3 (`style.css`)** — 
  - Bespoke typography pairings: *Cinzel*, *DM Sans*, and *Noto Serif Devanagari* (via Google Fonts)
  - Editorial cream, navy, and gold aesthetic with soft shadows and film-grain overlay
  - Fully responsive layout (Mobile, Tablet, Desktop)
  - Performant CSS keyframe animations and GPU-accelerated micro-interactions
- **Vanilla JavaScript (`script.js`)** — 
  - Interactive branded preloader
  - Custom dynamic cursor with magnetic button interactions
  - Scroll progress bar and active section navigation tracking
  - Scroll-triggered reveal animations via `IntersectionObserver`
  - Animated statistics counters and smooth parallax imagery
  - Zero third-party runtime dependencies

## 🚀 Getting Started

To view and run the website locally:

```bash
# Clone the repository
git clone https://github.com/vailism/youth-affairs-website.git

# Navigate into the project folder
cd youth-affairs-website

# Open index.html in any modern browser, or run a local static server:
# Using Python:
python3 -m http.server 8000

# Or using Node.js:
npx serve .
```

Then visit `http://localhost:8000` in your web browser.
